## LinkedIn / Instagram caption
I never know which seat to pick when I book a movie. The seat map is a grid of squares, and it doesn't tell you that row F in IMAX feels nothing like row F in a VIP room.

So I built a small open source fix. Pick a seat and you fly into it in 3D and see the screen the way you'll see it, with a score, a "feels like a 140-inch TV" number, and a check for whether the head in front covers the subtitles.

It runs on the web and iPhone, no server, no 3D engine, tiny. The rooms use typical sizes for now. With real auditorium data it would be exact.

@Cineplex, I'd love to see this in your app. Code is free to use: github.com/alireza12t/seatsight
